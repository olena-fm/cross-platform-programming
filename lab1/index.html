Smart Notes

Кросплатформний застосунок для створення нотаток

Про застосунок

Smart Notes — це навчальний приклад кросплатформного застосунку, який працює у браузері на різних пристроях: комп’ютерах, планшетах і смартфонах.

Для створення інтерфейсу використано HTML і CSS, а для взаємодії з користувачем — JavaScript.

Основні функції

  • Створення коротких нотаток
  • Перегляд списку нотаток
  • Видалення окремих нотаток
  • Адаптивний інтерфейс
  • Робота у будь-якому сучасному браузері
